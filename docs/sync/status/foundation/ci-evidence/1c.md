- In a narrow push run, a skipped matrix job shows under its unexpanded name, for example `Stage device · ${{ matrix.os }}`. Cosmetic.

## The defect in the Foundation job

`scripts/check-build-date.sh` printed, for each of its five rerun checks (resources.rc, icon.ico, Cargo.toml,
Cargo.lock, a new file under src/): `FAIL: build.rs did not run again after: a change to …`. Everything before
them passed (all 18 refusals, the five dates). The same script passes in the cloud container.

Cause, read from the log: the workflow sets `CARGO_TERM_COLOR: always` for every job, and the log shows cargo's
status words wrapped in colour codes (`ESC[1mESC[92m   CompilingESC[0m task_deck …`). `expect_rerun` looks in
`cargo check -v` output for the text ``Running `…task_deck-<hash>/build-script-build` ``; with colour on, the
escape sequence `ESC[0m` stands between `Running` and the space, so the pattern never matches and every rerun
check reports a failure although build.rs did run. The job log is run 44976738183, job 137068342627.
